# Documentação do site Arthur The Cannibal

Site oficial do lutador de MMA Arthur Henrique, The Cannibal (Brasília DF).

| Arquivo | Conteúdo | Quem usa |
|---|---|---|
| `perfil-comunicacao.md` | Quem ele é, ficha, pilares da narrativa, tom de voz, riscos e pendências | Todos: base de qualquer texto ou peça |
| `roteiro-grade-midias.md` | Conceito, grade das 2 sequências de vídeo (A e B), JSON de textos do site e autochecagem | Agente do template e geração de mídias |
| `HANDOFF.md` | Divisão de tarefas, status e recados entre quem trabalha no projeto | Todos |

## Regras do projeto

- Toda menção ao site antigo do template foi substituída; o conteúdo deste repositório é do
  projeto Arthur The Cannibal.
- Fatos sobre o Arthur só entram se estiverem em `perfil-comunicacao.md` com fonte. Não inventar
  números nem conquistas.
- Antes de publicar, resolver as pendências listadas no fim de `roteiro-grade-midias.md`.
